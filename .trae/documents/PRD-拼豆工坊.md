# 拼豆工坊 - 产品需求文档

## 1. 产品概述
一款专业级的像素拼豆（Perler Beads）设计工具 Web 应用，帮助用户创建、编辑和管理拼豆图案设计作品，支持多品牌色卡匹配和专业图纸导出。

- **核心价值**：降低拼豆设计门槛，提供智能颜色匹配和专业导出功能
- **目标用户**：手工爱好者、拼豆创作者、教育工作者
- **产品定位**：轻量级、专业化、设计友好的在线拼豆设计工具

## 2. 核心功能

### 2.1 用户角色
| 角色 | 使用方式 | 核心权限 |
|------|---------|---------|
| 访客用户 | 直接使用 | 浏览、创建、编辑、导出设计项目 |
| 注册用户 | 邮箱注册 | 数据云端同步、项目分享（未来扩展） |

### 2.2 功能模块

#### 2.2.1 项目管理模块
- **首页展示**：项目卡片列表，显示缩略图、项目名称、创建时间
- **项目创建**：自定义画布尺寸（8×8 至 128×128 像素）
- **项目操作**：重命名、复制、删除、导出
- **项目搜索**：按名称搜索项目

#### 2.2.2 画布编辑模块
- **画布系统**：
  - 可调节画布尺寸（8-128像素）
  - 显示网格线辅助对齐
  - 缩放和平移功能
- **绘图工具**：
  - 画笔工具（单像素绘制）
  - 橡皮擦工具（清除单个像素）
  - 填充桶工具（区域填充）
  - 取色器工具（从画布拾取颜色）
  - 颜色简化工具（减少使用的颜色数量）
- **历史记录**：
  - 撤销/重做功能
  - 操作历史栈

#### 2.2.3 颜色管理系统
- **内置品牌色库**：
  - Perler 品牌色卡（约 200+ 颜色）
  - Artkal 品牌色卡（约 400+ 颜色，含荧光色系）
- **颜色选择方式**：
  - 品牌色码搜索（如 "G17" → 荧光棕色）
  - HEX 值精确输入
  - RGB 值调整
  - 颜色面板可视化选择
- **调色盘功能**：
  - 用户自定义调色板
  - 最近使用颜色记录
  - 添加/删除颜色

#### 2.2.4 导出模块
- **导出格式**：
  - PNG 图片（高分辨率）
  - PDF 文档（包含网格线、色号标注）
- **导出选项**：
  - 是否显示网格线
  - 是否标注色号
  - 导出缩放比例

### 2.3 页面详情

#### 页面一：首页（项目列表）

## 3. 核心流程

### 3.1 项目创建流程
```
用户点击"创建项目"
    ↓
弹出尺寸设置弹窗
    ↓
输入/选择画布尺寸
    ↓
点击确认创建
    ↓
跳转至编辑器页面
    ↓
开始绘制
```

### 3.2 绘图工作流程
```
选择绘图工具（画笔/橡皮/填充/取色）
    ↓
选择或拾取颜色
    ↓
在画布上进行编辑
    ↓
实时预览效果
    ↓
保存或导出
```

### 3.3 颜色匹配流程
```
用户点击调色盘
    ↓
选择颜色输入方式
    ↓ A. 品牌色码搜索  B. HEX输入  C. 取色器
    ↓
系统匹配最近似品牌色
    ↓
添加到项目颜色列表
    ↓
应用到画布
```

### 3.4 导出流程
```
点击导出按钮
    ↓
选择导出格式（PNG/PDF）
    ↓
配置导出选项
    ↓
生成文件并下载
```

- **设计理念**：工具属性与创意氛围的平衡，专业但不冰冷

### 4.3 字体方案
- **主标题字体**："ZCOOL KuaiLe"（站酷快乐体）- 活泼有趣，适合品牌
- **正文字体**："Noto Sans SC"（思源黑体）- 清晰易读
- **代码/色号字体**：JetBrains Mono - 等宽字体显示色码

### 4.4 按钮与交互元素
- **按钮圆角**：8px - 12px
- **卡片圆角**：12px - 16px
- **阴影效果**：
  - 浅色模式：0 4px 6px rgba(0,0,0,0.1)
  - 深色模式：0 4px 6px rgba(0,0,0,0.3)
- **悬停效果**：轻微上移 + 阴影加深
- **点击效果**：轻微缩放 scale(0.98)

### 4.5 布局规范
- **页面边距**：桌面端 32px，移动端 16px
- **组件间距**：16px - 24px
- **网格系统**：12列布局（编辑器区域 8:4 分割）

## 5. 响应式设计

### 5.1 断点定义
- **桌面端**：≥ 1024px - 完整双栏布局
- **平板端**：768px - 1023px - 简化侧边栏
- **移动端**：< 768px - 单栏布局，工具栏折叠

### 5.2 移动端适配
- 编辑器切换为全屏画布模式
- 工具栏和调色盘变为底部抽屉
- 支持触摸绘制
- 双指缩放和拖动画布

## 6. 非功能性要求

### 6.1 性能要求
- 画布渲染：60fps 流畅绘制
- 页面加载：首屏加载 < 2秒
- 颜色匹配：< 100ms 响应
- 导出生成：< 5秒（标准尺寸）

### 6.2 可用性要求
- 操作反馈：< 200ms 视觉反馈
- 撤销/重做：支持 50+ 步操作历史
- 数据持久化：自动保存到 localStorage
- 错误处理：友好的错误提示

### 6.3 兼容性要求
- 浏览器支持：Chrome 90+, Firefox 88+, Safari 14+, Edge 90+
- 响应式支持：桌面、平板、手机全适配
- 无障碍支持：基础键盘导航和屏幕阅读器兼容

### 6.4 数据存储
- **本地存储**：使用 localStorage 存储项目数据
- **数据结构**：JSON 格式，易于导入导出
- **容量限制**：单个项目 < 5MB，整体 < 50MB
