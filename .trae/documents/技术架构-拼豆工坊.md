## 2. 技术选型

### 2.1 前端技术栈
- **核心框架**：纯 HTML5 + CSS3 + JavaScript (ES6+)
- **模块化**：采用 ES6 模块化开发（import/export）
- **绘图引擎**：HTML5 Canvas API
- **文件生成**：jsPDF（PDF导出）、原生 Canvas API（PNG导出）
- **样式方案**：CSS3 Variables（主题变量）+ CSS Grid/Flexbox 布局
- **字体资源**：
  - Google Fonts: ZCOOL KuaiLe, Noto Sans SC, JetBrains Mono
  - 通过 CDN 引入

### 2.2 数据存储
- **本地存储**：浏览器 localStorage
- **数据格式**：JSON
- **容量管理**：自动清理机制，限制总存储量

### 2.3 第三方库
| 库名称 | 版本 | 用途 | 引入方式 |
|--------|------|------|----------|
| jsPDF | 2.5.1 | PDF 文件生成 | CDN |
| html2canvas | 1.4.1 | 画布截图（可选） | CDN |

#### 颜色相似度算法
```javascript
// 使用加权欧几里得距离
// 人眼对绿色更敏感，所以绿色权重更高
colorDistance(c1, c2) {
  const rMean = (c1.r + c2.r) / 2
  const rDiff = c1.r - c2.r
  const gDiff = c1.g - c2.g
  const bDiff = c1.b - c2.b

  return Math.sqrt(
    (2 + rMean/256) * rDiff * rDiff +
    4 * gDiff * gDiff +
    (2 + (255-rMean)/256) * bDiff * bDiff
  )
}
```

## 7. 关键算法

### 7.1 洪水填充算法（Flood Fill）

```javascript
floodFill(startX, startY, newColor) {
  const targetColor = getPixel(startX, startY)
  if (targetColor === newColor) return

  const stack = [[startX, startY]]
  const visited = new Set()

  while (stack.length > 0) {
    const [x, y] = stack.pop()
    const key = `${x},${y}`

    if (visited.has(key)) continue
    if (x < 0 || x >= width || y < 0 || y >= height) continue
    if (getPixel(x, y) !== targetColor) continue

    setPixel(x, y, newColor)
    visited.add(key)

    stack.push([x + 1, y])
    stack.push([x - 1, y])
    stack.push([x, y + 1])
    stack.push([x, y - 1])
  }
}
```

### 7.2 颜色简化算法

```javascript
simplifyColors(maxColors) {
  const usedColors = getUsedColors()
  if (usedColors.length <= maxColors) return

  // 按使用频率排序
  usedColors.sort((a, b) => b.usage - a.usage)

  // 保留高频颜色，其余替换为最接近的品牌色
  const keepColors = usedColors.slice(0, maxColors)

  for (const color of usedColors) {
    if (!keepColors.includes(color)) {
      const nearest = findClosestBrandColor(color)
      replaceColor(color, nearest)
    }
  }
}
```

## 8. 性能优化

### 8.1 画布渲染优化
- 使用离屏 Canvas 缓存静态内容
- 增量更新：只重绘变化的像素
- requestAnimationFrame 节流绘制
- 大画布（64x64+）时启用网格线优化

### 8.2 存储优化
- 定期清理 localStorage（超过 50MB）
- 图片压缩：缩略图限制在 64x64
- 增量保存：只保存变化的部分

### 8.3 内存管理
- 限制撤销历史栈在 50 步以内
- 大项目自动禁用实时预览
- 及时释放 Canvas 资源

## 9. 浏览器兼容

### 9.1 ES6+ 特性
- 使用 Babel 转译（可选，如需兼容旧浏览器）
- 或设置 `<script type="module">` 仅现代浏览器使用

### 9.2 CSS 兼容性
- 使用 Autoprefixer 处理前缀
- 降级方案：Flexbox → Grid → 浮动布局
- CSS 变量回退方案

### 9.3 Canvas API
- 全支持：Chrome 4+, Firefox 3+, Safari 4+, Edge 12+
- 使用 `toBlob()` + `createObjectURL()` 替代 Base64 编码

## 10. 安全考虑

### 10.1 XSS 防护
- 用户输入的项目名称进行 HTML 转义
- 不使用 `innerHTML` 直接插入用户数据

### 10.2 存储安全
- 不存储敏感信息
- localStorage 数据不加密（纯前端应用）
