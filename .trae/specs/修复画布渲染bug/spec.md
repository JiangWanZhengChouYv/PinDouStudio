# 拼豆工坊 Bug 修复规范

## 问题背景

当前应用存在以下严重问题，导致画布无法正常使用：

1. **画布网格完全不显示** - 用户无法看到编辑区域
2. **颜色显示不正确** - Artkal/Perler 颜色无法正确渲染
3. **无法写入颜色** - 画笔工具无法在画布上绘制
4. **导出功能失效** - 无法导出 PNG/PDF
5. **项目列表不刷新** - 返回首页时项目列表不更新

## 问题根因分析

### 问题 1: 画布网格完全不显示

**可能原因：**
- CanvasEngine 的渲染逻辑有问题
- palette 颜色格式不正确导致渲染失败
- CSS 样式导致 canvas 不可见

### 问题 2: 颜色写入失败

**可能原因：**
- ToolManager 和 CanvasEngine 之间的颜色传递不一致
- `setPixel()` 方法接收的参数类型与实际传入不匹配
- 颜色索引系统设计混乱

### 问题 3: 导出功能失效

**可能原因：**
- `exportToCanvas()` 方法缺失
- palette 颜色访问方式不正确

### 问题 4: 项目列表不刷新

**可能原因：**
- 路由切换时没有触发项目列表刷新事件
- HomeController 没有正确绑定事件监听

## 修复目标

### 目标 1: 画布正确渲染
- 画布区域正常显示像素网格
- 每个格子清晰可见
- 网格线正确显示

### 目标 2: 颜色系统正常工作
- Artkal/Perler 颜色正确加载和显示
- 点击颜色可以选择并应用到画布
- 调色板正确管理颜色

### 目标 3: 绘图功能正常
- 画笔工具可以在画布上绘制
- 橡皮擦可以清除像素
- 填充桶可以填充区域

### 目标 4: 导出功能正常
- PNG 导出正常工作
- PDF 导出正常工作

### 目标 5: UI 交互正常
- 返回首页时项目列表正确刷新

## 修复约束

- **不改变现有 API 接口** - 保持与其他模块的兼容性
- **最小化改动** - 只修复问题，不重构代码
- **保持向后兼容** - 不影响已有项目数据

## 验收标准

### AC-1: 画布渲染
- **Given**: 用户打开编辑器
- **When**: 加载项目后
- **Then**: 画布显示清晰的像素网格，每个格子边界可见
- **Verification**: `human-judgment`

### AC-2: 颜色选择和绘制
- **Given**: 用户在调色盘选择颜色
- **When**: 点击颜色后
- **Then**: 颜色被选中，右侧预览更新；点击画布可以将颜色绘制到对应格子
- **Verification**: `human-judgment`

### AC-3: 导出功能
- **Given**: 用户点击导出按钮
- **When**: 选择格式并确认导出
- **Then**: 文件正确下载到本地
- **Verification**: `programmatic`

### AC-4: 项目列表刷新
- **Given**: 用户在编辑器编辑项目后返回首页
- **When**: 点击返回按钮
- **Then**: 首页项目列表显示最新状态，包括刚刚编辑的项目
- **Verification**: `human-judgment`
